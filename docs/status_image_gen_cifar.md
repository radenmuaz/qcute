# image_gen_cifar status

## What it is

Single-file (`image_gen_cifar/run_causalattn.py`), hard-forked from the `qcute_lagcodec` idea — no imports from that package, every primitive rewritten locally. CIFAR-10 hierarchical latent-AR image generator: a 3-level causal-LM encoder produces PQ codes for each row of a scanline-flattened image, and a plain GPT-style decoder autoregresses bytes conditioned on those codes.

## Architecture

- **Data**: row-major flatten of the 32x32x3 image (1024 pixel timesteps). Pixel input embed is PQ-style: 3 independent 256-entry per-channel (R/G/B) tables, summed. Train = full 50k CIFAR-10 train batches; val = the 10k test batch doubles as val (no separate held-out split, per user direction).
- **Encoder** (`ImageEncoder`/`EncoderLevel`): 3 causal-LM levels, `strides=(2,4,4)` (product 32 == image width) so level2's 32 output codes land exactly one-per-row. Each level's code head mean-pools (`code_extract_mode="mean"`, default) or last-idx-pools (`"last_idx"`) its stride-window of hidden states before a linear projection to a **product-quantized (PQ) categorical code**: `code_vocab=16` per chunk, `pq_chunks=4` (combinatorial capacity 16^4=65536 per code), gumbel-hard STE (deterministic argmax forward, soft gradient backward, no injected noise). Levels 1/2 also carry an NTP head (auxiliary loss) so they can act as free-running generative priors (`sample_codes()`) — level0 has none, its generative role is the Decoder.
- **Decoder** (`Decoder`): plain GPT-style decoder-only causal self-attention LM — codes are embedded and concatenated as ordinary tokens (no cross-attention, no seed-token/block-folding machinery). Batched 32-ways over image **columns** (one clone per column, zero inter-clone communication by default — see `col_group_size`). Each column-clone autoregresses top-to-bottom over its 32 rows: `[level2_code, level1_code, level0_code(seed), R, G, B]` per row (`decoder_mode="seq"`, default) or `[level2,level1,level0-seed,RGB-packed]` (`"mtp"` — predicts R/G/B simultaneously from the seed's hidden state, no within-pixel chaining).
- **Causality**: every code fed into row *r*'s decode is **lagged by one row** (computed from rows < r only; row 0 uses a learned BOS `bos_l2`/`bos_l1`/`bos_l0`) — the true encoder codes for row *r* are themselves computed causally over pixels through the end of row *r*, so using them unlagged would leak that row's own not-yet-generated pixels into its own conditioning. This makes bpb a genuine chain-rule NLL, not an ELBO-style reconstruction bound. Kept BOS (vs. leaving row 0 unsupervised, the more common decoder-LM convention) deliberately: preserves genuine unconditional whole-image generation and a complete 32-row bpb, at the cost of 3 extra learned vectors — BOS doesn't block prompting either (see below).
- **Attention**: Qwen3-style RoPE + per-head QK-norm + **GQA** (`n_kv_heads`, default `None` → `max(1, n_heads//4)`, matching `qcute_lagcodec`'s own default).
- **Column entanglement** (`ColumnMixAttention`, `col_group_size` config): non-causal self-attention across the column axis, applied only to each row's already-fully-known code conditioning (never to byte predictions, so it can't leak). `col_group_size=1` (default) = SISO, today's fully-independent column-tracks, a true no-op. `col_group_size=img_size` = MIMO, full entanglement. In between = grouped (GQA-/group-conv-style partitioning). One shared module instance mixes l2/l1/l0 conditioning independently.
- **Class conditioning** (`class_conditional`, off by default): a learned `class_embed(y)` broadcast-added to *every* row's conditioning (decoder) and *every* AR step (encoder's generative priors) — not just a BOS-style one-time injection, to avoid the signal diluting over the sequence.
- **KV cache**: real incremental decoding (`forward_incremental`/`step`, `KVCache.k/v`) used by default (`use_cache=True`) for both `sample_codes()` and `Decoder.generate()`. The naive O(T^2) full-recompute path is kept (`use_cache=False` / `generate_nocache`) purely as a correctness reference — `check_kv_cache_consistency()` (wired to `--check_kv_cache`) asserts byte-exact greedy agreement between the two paths. Verified locally: match rate 1.0 across `seq`/`mtp` decoder modes, GQA, all `col_group_size` values, and class-conditional — see git history for the exact test commands if this needs re-verifying after a change.
- **Utilization metric**: `codebook_utilization()` — per-level, per-PQ-chunk usage-perplexity normalized to [0,1] (1.0 = batch uses every code uniformly, →0 = collapsed), logged only (`util0`/`util1`/`util2`), not part of the loss. There used to be an `entropy_reg` loss term for anti-collapse regularization; removed in favor of just watching this metric.
- **Loss**: decoder byte cross-entropy (the main bpb-bearing signal, trains the whole stack end-to-end through the STE-quantized codes) + `ntp_aux_weight * ntp_loss` (auxiliary, trains level1/level2's NTP heads — the ones reused as generative priors at inference). Gradient flow end-to-end from decoder loss to the raw pixel input embeddings (`r_embed`/`g_embed`/`b_embed`) confirmed nonzero.

## Known limitation (not yet built)

The "macro-step interleaved" redesign discussed and agreed on but **not implemented**: today, training's encoder pass runs as one global parallel forward over the whole image (standard AR-training trick, causal masking makes this exact), and generation runs two fully separate phases (`sample_codes()` free-runs the whole code hierarchy first, *then* `Decoder.generate()` decodes bytes from it) rather than a genuinely interleaved per-row loop (encode row *t* → decode → sample row *t+1* → feed back → repeat). The lag-1-row hack stands in for what that interleaving would give for free. Revisit if TODO resurfaces.

## Config / invocation

```
uv run python3 -m image_gen_cifar.run_causalattn --config image_gen_cifar/configs/base.py
```
`--config` loads a config file's module-level vars as new argparse defaults; explicit CLI flags still override those. Every run's resolved config, a copy of the `--config` file used, and checkpoints (`best.pt`/`last.pt`) land in `image_gen_cifar/logs/<run_name>/` (not repo-root `logs/`). `train.log` there tees full stdout/stderr (tqdm bar included) for `tail -f`. Training loop is **epoch-based** (`--epochs`, default 100), not step-based; `--eval_every_epochs` (default 1) runs val eval + saves a tiled PNG grid of `--qual_gen_n` generated samples (`save_sample_grid`, KV-cached generation) every N epochs.

`configs/base.py`: `d_model=256, n_layers=1, n_heads=4` (GQA default), `code_vocab=16, pq_chunks=4`, `class_conditional=False`, `batch_size=8` (the decoder's effective batch is `batch_size * img_size` columns — keep small on MPS; `batch_size=32` OOM'd at ~9GiB on this machine's MPS budget, `batch_size=8` runs stably).
